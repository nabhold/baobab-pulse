# Baobab Pulse

Baobab Pulse is the Nabhold intelligence-engine repository. Its runtime remains
deliberately unselected; Foundation 4 establishes repository governance without
prematurely choosing an analytics or AI stack.

Codespaces uses `ghcr.io/nabhold/baobab-dev:1.2.6`. The SHA-pinned `foundation`
workflow validates the development contract, reproducible inputs, ownership,
and source, dependency, secret, and configuration security.
